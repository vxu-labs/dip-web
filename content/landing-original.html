BEFORE YOU START

Where does my project data live?

Durable project history lives in .dip/ beside your code and travels through Git when committed. Runtime queues and local coordination stay on your machine. Review captured data before publishing a repository; redaction cannot guarantee every secret is removed.

Does DIP make extra model calls?

Automatic capture makes no model calls. Your existing coding agent uses its normal tool loop for planning and task management, which adds measurable overhead.

Does it coordinate agents across machines?

Live coordination covers one Git worktree family on one machine. Independent clones and machines can share history through Git, but Git alone does not guarantee exclusive live ownership.

How do I know the hooks are working?

Run dip doctor to inspect configuration, service health and observed capture. Configuration alone does not prove a running agent has loaded or trusted its hooks. Restart the agent and review its trust prompts.

How can I contribute?

Try a first-run workflow, improve the docs, or help with dashboard accessibility. Start with the contributor guide and open issues.
